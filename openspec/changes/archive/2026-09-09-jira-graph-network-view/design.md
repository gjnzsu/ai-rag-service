## Context

已有默认分组 SVG 全景，overview 提供最多 100 节点和 500 边。当前 AIPLAT 为 35 节点/29 边，包含一条真实跨 Epic BLOCKS。

## Goals / Non-Goals

Goals：Grouped / Network 即时切换、稳定自动布局、节点拖动、直接邻居高亮、来源与下钻复用。
Non-Goals：新图关系、风险推断、聚类分析、后端数据迁移、持续物理动画、任意大图优化。

## Decisions

- 在原 panorama.js/SVG 上实现有界确定性布局，Epic 层级吸引、节点排斥、真实依赖牵引；计算固定步数后静止。保留现有分组默认布局，Network 为用户显式选择。
- 不引入 CDN 或新运行依赖；35–100 节点的 PoC 可在本地完成有界计算。若之后规模增加再评估专用图形库。
- 节点形状区分 Epic/事项，颜色继续表达状态；通过父 Epic 标识保留归属辨识。布局距离不表示业务关系，只有源数据边表示关系。
- Network 支持 pointer 拖动节点并同步更新端点；背景拖动继续平移。坐标转换使用 SVG 屏幕矩阵，缩放后拖动仍正确。
- 点击或 Enter/Space 选中节点，突出直接邻居和关联边，其余淡化；按钮清除高亮。Fit 重置视窗以包含全部节点，Reset layout 恢复确定性布局。
- 保留快照数据与点击回调；布局切换无网络请求。无新的后台计时器或持续动画，移除页面不会泄漏模拟任务。

## Risks / Trade-offs

稀疏图仍呈现多个群组，不人为添加连线。节点及标签重叠通过布局间距和拖动缓解，极限 100 节点不保证零交叉。重点检查真实跨 Epic 关系与 100 节点合成样例。

## Migration Plan

只更新本地静态文件；保留 Grouped 模式作为回退。旧快照、API 与数据库不变。验证后同步新增演示要求并归档此次增量变更。

## Execution

第一段最多 50 分钟：文档、失败浏览器测试、实现。第二段最多 50 分钟：真实/合成浏览器验收、完整质量门禁、操作说明和归档。用户已授权无需中途暂停；不提交、推送或部署。
